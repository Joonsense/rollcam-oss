# RollcamSans

Subset of [Pretendard](https://github.com/orioncactus/pretendard) 1.3.9 by Kil Hyung-jin, used for Hangul in images the app draws with Skia (the roll share image).

- License: SIL Open Font License 1.1, full text in `OFL.txt`; the copyright and license also stay in each font's name table.
- Modified (subset to all 11,172 Hangul syllables + ASCII; before 0.4.1 only KS X 1001's 2,350), so renamed: the OFL reserves the name "Pretendard" for unmodified fonts.
- Rebuild: `uv run scripts/make-font.py <Pretendard-Regular.otf> <Pretendard-Bold.otf>`
